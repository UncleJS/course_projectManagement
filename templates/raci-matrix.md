## RACI Definitions

| Code | Meaning | Rule |
|---|---|---|
| **R** | **Responsible** | Does the work. Can be shared across multiple people. |
| **A** | **Accountable** | Owns the outcome; the "buck stops here." **One per task only.** |
| **C** | **Consulted** | Provides input before the action/decision. Two-way communication. |
| **I** | **Informed** | Told of the outcome. One-way communication. No input required. |

### Common Errors to Avoid

- More than one **A** per task — causes confusion about who owns the outcome.
- No **A** for a task — creates an accountability vacuum.
- Too many **C**s — slows decisions; reserve for genuine subject-matter input.
- **R** without **A** on the same row — someone is doing work no one owns.
