## Engagement Level Key

| Code | Level | Description |
|---|---|---|
| **U** | Unaware | Unaware of the project or its implications |
| **R** | Resistant | Aware but opposed to the project |
| **N** | Neutral | Aware but neither supportive nor opposed |
| **S** | Supportive | Aware and supportive of the project |
| **L** | Leading | Actively engaged and championing the project |

*C = Current engagement level | D = Desired engagement level*
